# 修改計畫：首頁戰績側邊欄（2026-11-18）

> 狀態：**規劃中**。依 `docs/dev_rules.md`，先做靜態設計稿並經使用者核准後才實作，一次一個模組。

## 一、需求
首頁加入可收合的側邊欄，依分區列出各隊戰績。

## 二、已確定的決策（2026-11-18 與使用者確認）

### 位置與開合
- 桌機：側邊欄在右側，預設展開，可收合。收合狀態以 `localStorage` 記住，這只是單一瀏覽器的個人偏好；讀寫失敗時退回預設展開。
- 手機：以按鈕叫出抽屜。

### 欄位與排列
- 欄位：W、L、PCT、GB、L10、STRK。
- 分組：依六個分區分組，順序為美聯東、中、西區，接著國聯東、中、西區。
- 排序：分區內依 `divisionRank` 排序。
- 標記：已確定晉級的球隊在隊名旁顯示 API 的 `clinchIndicator`（如 z、y、x、w），並附圖例說明。

### 休賽季
- 顯示上季最終戰績，標題註明「2026 例行賽最終戰績」，直到新球季開打。
- 賽季判斷與名單頁相同，沿用 `resolve_roster_context`：
  - 開季前：用前一年。
  - 賽季中：用當年，標題為「{年} 例行賽戰績 · 更新於 …」。
  - 季後賽結束後：用當年最終戰績。

### 桌機兩欄捲動（2026-11-18 使用者回饋）
- 側邊欄不使用 sticky，也不做內部捲動，與主內容一起隨頁面捲動。
- 兩欄頂端對齊「最新一期」卡片，以版面結構對齊，不寫死像素值。

### 左欄新增：今日賽事預告（2026-11-18 與使用者確認）
- 左欄順序：最新一期 → **今日賽事預告**（休賽季改為開季倒數與本週人事異動精選）→ 30 隊名單入口 → 近期。
- **賽季中「今日賽事預告」**：
  - 範圍：台北時間當天中午之後開打的比賽，約等於美國當日賽程。
  - 每場顯示：
    - 開賽時間（台北時間）
    - 對戰（隊徽、中文隊名、目前戰績）
    - 預定先發投手（姓名、本季勝敗、ERA；未公布顯示「未定」）
  - 不顯示球場。
- **休賽季替代內容**（兩者都放）：
  1. **開季倒數**：依賽季 API 的春訓開始日與開幕日，顯示「距離春訓 N 天、距離開幕戰 N 天」。
  2. **本週人事異動精選**：近 7 天大聯盟層級的交易、自由球員簽約、延長合約，套用現有過濾規則，並以 Gemini 翻譯。
- 資料來源：
  - 賽程：`/api/v1/schedule?sportId=1&date=...&hydrate=probablePitcher(...)`。實作時確認先發投手數據的 hydrate 寫法。
  - 賽季日期：`/api/v1/seasons/{year}`。
  - 人事異動：既有 transactions API。

### 設計稿核准（2026-11-18）
- 使用者已核准 `docs/mockups/index-standings.html`。預設為休賽季版；網址加 `?mode=season` 為賽季版，加 `?state=error` 為戰績錯誤版。
- 手機上的戰績按鈕：右上角、緊貼右緣的書籤式標籤，只放長條圖圖示，不放文字，保留 `aria-label="戰績"`。桌機收合後的窄欄使用同一圖示。
- 側邊欄隊名以「小隊徽＋縮寫」顯示，完整中文隊名放在 `title`／`aria-label`。
- 休賽季「本週人事異動精選」依日期由新到舊排列，不依球隊分組。
- 實作時補上：
  - 賽事預告副標標示台北日期，例如「台北時間 11/19（四）凌晨起 · N 場」，避免讀者誤以為是當天凌晨。
  - 實作前先對照 MLB 官方說明，確認 clinch 標記（z／y／x／w）的定義。

## 三、資料
- API：`GET /api/v1/standings?leagueId=103,104&season={年}&standingsTypes=regularSeason`，回傳 6 個分區（2026-11-18 已實測）。
- 每隊可用欄位：
  - `wins`、`losses`、`winningPercentage`
  - `gamesBack`（領先者為 `-`）
  - `divisionRank`
  - `streak.streakCode`（如 `W3`、`L1`）
  - `clinchIndicator`
  - `records.splitRecords` 中 `type == "lastTen"` 的 wins／losses
- 隊名、縮寫、隊徽沿用 `TEAM_META`，以 team id 對應。
- 產生方式（暫定，實作時確認）：每日產生首頁時一併抓取戰績，直接由 Python 渲染成首頁 HTML 的一部分（靜態，不需前端 fetch）。
  - 抓取失敗時，側邊欄顯示「戰績暫時無法取得」，不影響首頁其他內容與戰報流程。
