# 開發日誌：2026-11-24 焦點球員評分改版

## 📝 修改摘要

焦點球員（Notable Performers）改用壘打數與 Game Score 風格評分，打者與投手分開評分、分開入選。對應 commit：`cf864be`。

## 🛠️ 詳細改動內容

- `mlb_daily/games.py`：新增 `batter_score`、`pitcher_score`；評分權重與入選門檻改為模組層級常數。
  - 打者分數 = TB + BB + HBP + SB − CS + 0.5×(R + RBI) − 0.25×(AB − H)。
  - 投手分數 = 2×出局數 + K − 2×BB − 2×H − 3×R − 6×HR；後援投手 0 失分且拿到救援或中繼成功再 +2；勝投不加分。
  - 打者每場最多 4 人，前 2 名分數 ≥ 3 即入選，第 3 名起須 ≥ 5。
  - 投手每場最多 3 人，第 1 名分數 ≥ 8 即入選，其餘先發須 ≥ 20、後援須 ≥ 10。
  - 每位入選者附 `norm` = 分數 ÷ 門檻（打者 5、先發 20、後援 10）；`top_focus_score` 改取 `max(norm)`。
- `tests/test_fetch_mlb.py`：測試同步更新。
- `docs/architecture.md`：焦點球員規則與 `summary` 說明同步更新。

## ✅ 驗證結果

- `python -m unittest discover -s tests`：902 個 unittest 全數通過。
- 用 2026 年兩場真實比賽試跑確認正常：世界大賽 G5（gamePk 849799）、9/22 CWS 14:11 KC（gamePk 824061）。
- 真實 boxscore 中確有 `totalBases`、`hitByPitch`、`caughtStealing`、`holds` 等欄位；手算分數與程式輸出一致。
