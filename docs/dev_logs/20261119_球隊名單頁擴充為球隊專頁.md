# 開發日誌：2026-11-19 球隊名單頁擴充為球隊專頁

## 📝 修改摘要

把 `teams.html` 從「球隊名單」擴充為「球隊專頁」，由上而下四個區塊：球隊摘要、近期動態（近 30 天）、隊內數據王、名單。設計稿與計畫見 `docs/mockups/teams.html`、`docs/plans/20261119_球隊專頁設計.md`（使用者已核准設計稿）。名單區塊完整保留既有功能（SP／RP／野手三張可排序表、慣用手 L/R/S 標籤、二刀流標記、Savant 連結、更新失敗提示）。

## 🛠️ 詳細改動內容

- `mlb_daily/team_page.py`（新）：`compute_leaders`（隊內數據王與門檻）、`build_recent`（近 30 天人事異動加入／離開分類與新聞隊名比對）、`postseason_result`、`build_record`、`tracked_names`、`make_extras`。
- `mlb_daily/rosters.py`：`fetch_rosters(today, extras_factory=None)`，附加資料併入各隊 JSON；工廠或單隊附加資料失敗只印警告，名單照寫。
- `mlb_daily/cli.py`：`--rosters` 傳入 `team_page.make_extras`；不新增 CLI 選項，也不改 workflow（「Restore history from gh-pages」已還原 `data/daily/`、`data/playoffs.json`，「Update Team Rosters」又在 Generate Daily Report 之後）。
- `mlb_daily/standings.py`：每隊多存 `run_diff`（缺值為 `None`）。
- `mlb_daily/config.py`：`TEAM_PAGE_RECENT_DAYS=30`、`TEAM_PAGE_NEWS_LIMIT=5`、`TEAM_PAGE_LEADER_MIN_PA=300`、`TEAM_PAGE_LEADER_MIN_IP=50`。
- `assets/teams.js`：合併設計稿的新區塊（沒有整檔覆蓋）；人事異動每欄先顯示 8 筆、「顯示全部（N）」展開（重繪後保留展開狀態）；新聞連結只接受 http(s)；所有文字以 `textContent` 寫入。
- `assets/style.css`：加入設計稿的摘要、近期動態、數據王樣式與展開按鈕；`.hand` 與深淺色色值不動。
- `teams.html`：`<title>` 與 h1 改為「球隊專頁」，導覽列文字維持「球隊名單」。
- 測試：新增 `tests/test_team_page.py`；`tests/test_fetch_mlb.py` 的 `test_writes_all_teams_and_index` 改為預期各隊 JSON 多出 `summary`、`recent`、`leaders`。
- 文件：`docs/architecture.md`（新增「球隊專頁」一節與模組表）、`README.md`、`docs/progress.md`、計畫文件（狀態改為「已核准，實作完成」並補預設決定）。
