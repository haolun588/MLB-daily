# 開發日誌：2026-08-01 優化單場焦點球員標籤排列

## 📝 修改摘要

本工作階段針對「單場焦點球員 (Key Performers)」卡片內的長打 (HR) 與盜壘 (SB) 標籤進行 Flexbox 版面優化，解決過去標籤拉開至兩端的問題，使其統一靠右對齊並併排展示。

---

## 🛠️ 詳細改動內容

1. **模板與 CSS 調整 (`templates/report_template.html`)**：
   - 新增 `.performer-tags` CSS 樣式：
     ```css
     .performer-tags {
       display: flex;
       gap: 0.35rem;
       align-items: center;
     }
     ```
   - 將靜態範例球員卡片中的標籤包裹於 `<div class="performer-tags">` 容器中。

2. **Python 數據解析與渲染腳本 (`fetch_mlb.py`)**：
   - 修改打者與投手卡片的 HTML 生成 logic，將 `performer-tag` 標籤包裹在 `<div class="performer-tags">` 容器內。
   - 藉由外層 `.performer-name-row` 的 `justify-content: space-between`，將球員姓名/隊伍放在左邊，將標籤容器推至最右邊。當同一打者同時有 HR 與 SB 時，兩個標籤會於容器內以 `0.35rem` 間距緊鄰併排。

3. **產出驗證**：
   - 重新執行戰報生成，確認產出的 HTML（如 `reports/2026/07/2026-07-20.html`）標籤靠右對齊且視覺呈現良好。
