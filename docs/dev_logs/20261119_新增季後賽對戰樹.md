# 開發日誌：2026-11-19 新增季後賽對戰樹

## 📝 修改摘要

新增「季後賽」：獨立頁 `playoffs.html` 顯示整屆對戰樹（外卡、分區、聯盟冠軍賽、世界大賽與冠軍），並在首頁側欄加小卡。非季後賽期間顯示上一屆結果。設計見 `docs/plans/20261119_季後賽對戰樹設計.md`。

- `mlb_daily/playoffs.py`（新）：`fetch_postseason`、`parse_postseason`（勝場計算、延賽去重、外卡到分區的對應與輪空判斷）、`generate_playoffs`、頁面與首頁小卡渲染。

- `config.py`、`storage.load_playoffs`、`index_page`：小卡放在排行榜小卡下方，資料賽季與當前賽季相同才顯示；`_fallback_roster_context` 在 1–3 月改回傳 `year - 1`。

- 導覽列加「季後賽」；`.gitignore` 加 `/playoffs.html`。
