## 🛠️ 詳細改動內容

- **翻譯重試與備用模型（`0bd12b6`）**：Gemini 遇 429／5xx／逾時最多重試 3 次（間隔 5、15、45 秒，尊重 `Retry-After`，上限 120 秒），其他 4xx 不重試；主模型持續失敗時改用備用模型 `gemini-3.6-flash`（`GEMINI_FALLBACK_MODEL` 可覆寫或停用）。起因：2026-11-17 戰報翻譯因 `gemini-3.5-flash-lite` 回應 HTTP 503 而退回英文。文件與測試同步。
- **口語簡稱（`2108823`）**：新增 `TEAM_SLANG_ALIASES`（Yanks、D-backs 等）併入 Gemini 球隊名稱對照，提示詞要求列舉中的球隊名稱與簡稱也須翻成中文。起因：11/17 新聞標題中的 Yanks、Mets 未翻譯。
- **交易 Savant 連結（`d8d7495`）**：MLB API 對同一筆交易每位球員各給一筆紀錄，原本以描述去重會丟掉其餘球員；改為合併為 `persons` 清單並全部渲染連結。
- **歷史索引只存 gh-pages（`6b8136a`）**：main 不再追蹤 `reports/metadata.json` 與 `index.html`；workflow 產生報表前先從 gh-pages 取回 `metadata.json`，取不到即失敗；移除 auto-commit 回 main 的步驟；`.gitignore`、`README.md`、`docs/architecture.md`、`docs/dev_rules.md` 同步。
- **專案協作規則（`17cb61f`、`313c1e5`）**：新增專案 `CLAUDE.md`，寫入子代理分工規則；後續將繁體中文回覆列為最優先規則。
- **規劃文件（`dfe0b0c`、`a056a6f`）**：更新 `progress.md` 補產戰報進度，新增 `docs/plans/20261118_新功能規劃.md`；排行榜放置位置定案。
