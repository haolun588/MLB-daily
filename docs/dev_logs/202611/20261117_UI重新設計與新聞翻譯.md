## 🛠️ 詳細改動內容

- **模組 H（`55673ac`）**：新增 `docs/mockups/`（首頁、賽季戰報、休賽季快報、歷史存檔四頁與共用 `style.css`、`archive.js`、假資料）；設計方向為深色記分板／報紙體育版風格，Noto Sans TC + JetBrains Mono，跟隨系統深淺色；新增 `.claude/launch.json` 作為設計稿本機預覽設定。
- **階段 1（`c25ad77`）**：新增共用 `assets/style.css`、`templates/report.html`（戰報與休賽季快報共用）、`templates/index.html`；渲染拆為小函式，所有 API 字串輸出前一律 `html.escape`；無賽事日改產「休賽季快報」，與賽季頁共用 `render_page`；首頁改由 metadata 全量重新產生，新增 `archive.html` 與 `assets/archive.js`（依月份分組，含讀取中／失敗／空狀態）；metadata 新增 `type`、`transactions_count`；提前完成模組 F 部分項目（打者補 SO/2B/3B 與累計、代跑者納入、搜尋精確縮寫優先、移除測試用歷史資料等）；刪除 `templates/report_template.html` 與舊 `index.html` 內容。
- **階段 2（`4420e94`）**：新增 `fetch_text` 與 `fetch_daily_news`，讀取 MLB 官方 RSS、只取報表日（台北時間）當天新聞，最多 12 則；連結與圖片僅接受 https 的 `www.mlb.com`／`*.mlbstatic.com`；賽季戰報與休賽季快報加入新聞區塊；人事異動須至少一方為大聯盟球隊，`signed`／`minor league` 改為單字比對（避免 `assigned` 誤判）；休賽季無新聞也無異動時不發 Discord，休賽季通知改為「休賽季快報：新聞 N 則、人事異動 M 筆」。
- **階段 3（`aee93b6`）**：以標準函式庫呼叫 Gemini Interactions API（預設 `gemini-3.5-flash-lite`，可用 `GEMINI_MODEL` 覆寫，金鑰只放 header）；翻譯 RSS 新聞標題、單場新聞標題與摘要、人事異動描述；球員姓名逐字保留、球隊名稱依內建對照表；整頁一次批次翻譯（每批最多 60 則），單則或整批失敗時退回英文原文；metadata 新增 `translated`；加入診斷日誌；workflow 產生步驟帶入 `GEMINI_API_KEY`。
