# 開發日誌：2026-11-18 休賽季每週總整理

## 📝 修改摘要

新增「休賽季每週總整理」：休賽季每週一（台北時間）把上一個 ISO 週的人事異動與新聞彙整成 `reports/weekly/YYYY-Www.html`。資料全部來自每日戰報存下的 `data/daily/YYYY-MM-DD.json`，不重抓 API、不重新翻譯。設計見 `docs/plans/20261118_休賽季每週總整理設計.md`。

使用者核准的三項決定：(1) 資料不足 7 天採方案 A（有 ≥1 天就照產並標示涵蓋天數，0 天不產不通知）；(2) 拿掉「選擇權」分類；(3) `settings/offseason_calendar.json` 先放空檔上線。

## 🛠️ 詳細改動內容

- `mlb_daily/weekly.py`（新）：週次計算（ISO 週、`fromisocalendar` 驗證）、讀快照（損壞檔略過並警告）、分類、各隊動態（交易雙方都記、並列最忙都標）、新聞精選（link 去重、台日韓 +2、重點異動球員 +1、同分新到舊、10 則）、台日韓標註、下週日程、渲染與 `generate_weekly_report`（含條件判斷與索引寫入）。
- `templates/weekly.html`（新）、`assets/style.css`（新增週報樣式）。
- `mlb_daily/config.py`：`WEEKLY_CATEGORIES`、`WEEKLY_TYPE_CATEGORY`、`WEEK_KEY_RE`、各路徑與 `SITE_BASE_URL` 等常數。
- `mlb_daily/storage.py`：`write_daily_snapshot`、`write_weekly_report`、`load_weekly_index`／`save_weekly_index`／`latest_weekly_entry`。

- `mlb_daily/cli.py`：`--weekly`、`--week`、`--force`、`--notify-weekly`；成功時印 `weekly_week=`、`weekly_url=` 供 workflow 使用。
- `assets/archive.js`：讀 `reports/weekly/index.json` 顯示「每週總整理」清單（讀不到不顯示）。
