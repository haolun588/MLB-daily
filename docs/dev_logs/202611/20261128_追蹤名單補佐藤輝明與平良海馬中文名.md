# 開發日誌：2026-11-28 追蹤名單補佐藤輝明與平良海馬中文名

## 📝 修改摘要

台日韓追蹤名單從 MLB API 動態名單（`data/watchlist.json`）自動抓入佐藤輝明、平良海馬，但 `settings/watchlist.json` 沒有這兩人的中文名，網站因此顯示英文名。本次在設定檔補上兩人中文名；並確認目前沒有自動中文化機制，記錄為已知限制。

## 🛠️ 詳細改動內容

### 追蹤名單補名

- `settings/watchlist.json`：兩筆皆置於日本區 松井裕樹 之後、李政厚 之前。
  - 佐藤輝明（Teruaki Sato），MLB id 831664（`87cecb9`，11/27）
  - 平良海馬（Kaima Taira），MLB id 838343（`15cb467`，11/28）
- ID 以 `https://statsapi.mlb.com/api/v1/people/search?names=...` 查得。
- 僅設定檔變動，不需改程式。

### 已知限制：缺中文名只顯示英文名，且沒有提醒

- 目前沒有自動中文化機制。`mlb_daily/watchlist.py` 的 `load_watchlist` 對 settings 沒有的動態球員，`name_zh` 直接使用 `name_en`，並標 `has_zh=False`。
- `has_zh` 除測試外沒有任何地方使用，缺中文名時不會有警告，需靠人工發現。
- 曾提議在產生戰報時列出缺中文名的球員作為提醒，使用者決定先不做，列為候選待辦。
