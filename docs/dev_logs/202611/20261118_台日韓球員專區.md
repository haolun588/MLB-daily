# 開發日誌：2026-11-18 台日韓球員專區

## 📝 修改摘要

新增「台日韓球員專區」：依固定追蹤名單，在每日戰報與首頁顯示名單球員的人事異動、相關新聞與（賽季中）當日打擊／投球成績。設計見 `docs/plans/20261118_台日韓球員專區設計.md`。

## 🛠️ 詳細改動內容

- `settings/watchlist.json`：20 位名單球員（台灣、日本、韓國），部分有新聞比對別名；workflow `exclude_assets` 排除 `settings`。
- `mlb_daily/watchlist.py`（新）：名單讀取、異動／新聞／boxscore 比對、`spotlight` 資料組成、戰報與首頁渲染。
- `transactions.py`：拆出 `fetch_raw_transactions`；`news.py`：新增 `fetch_all_daily_news`（全部新聞與 `summary`，顯示仍最多 12 則）。
- `translate.py`：名單異動與名單新聞標題併入同一批次，相同字串不重送。
- `report.py`、`index_page.py`、兩個模板、`assets/style.css`：新增 `SPOTLIGHT` 插槽與樣式；metadata 新增 `spotlight`。
- 多名單球員的同一則新聞／異動只存一次，其他球員顯示「（同上則…）」；休賽季球隊由異動推算。
- `tests/test_watchlist.py` 與四個新 fixture。

## ✅ 驗證結果

- `python -m unittest discover -s tests` 381 個測試全過。

## 🔍 本機實跑與修正

- 2026-10-29 實跑（`python fetch_mlb.py --date 2026-10-29 --no-notify`）：鄭宗哲交易、鈴木誠也／今永昇太／金河成自由球員異動皆正確顯示。
- 發現並修正 bug：API 對同一筆交易回傳兩筆紀錄，其中無 person 的紀錄 to/from 方向相反，造成鄭宗哲標題顯示「台灣・紅襪」。`match_transactions` 改為優先取 person 為名單球員的紀錄，其次取有 person 的紀錄；`filter_major_league_transactions` 去重也採同樣原則。新增測試後共 382 個測試全過。

- 2027 開季用真實 boxscore 驗證打擊／投球成績；休賽季真實日期本機驗證。
