# 開發日誌：2026-11-27 iPhone 主畫面圖示

## 📝 修改摘要

iPhone Safari「加入主畫面」後桌面圖示沒有 logo。原因是網站只有 SVG favicon，iOS Safari 不支援 SVG 當主畫面圖示，需要 PNG 的 apple-touch-icon。修正於 commit `4399a31`；第一次修完仍未生效，是因為新圖示尚未部署，手動補部署後解決。

## 🛠️ 詳細改動內容

### 修正（`4399a31`）

- 新增 `site/assets/apple-touch-icon.png`：180x180 不透明 RGB PNG，以 Pillow 依 `favicon.svg` 幾何繪製（`#0d1014` 底、`#ece8df` 菱形描邊、`#e5484d` 圓點）；產生腳本未進 repo。
- `site/archive.html`、`site/teams.html`、`templates/index.html`、`leaders.html`、`playoffs.html`、`report.html`、`weekly.html`：在 favicon link 下一行加 `<link rel="apple-touch-icon" href="...">`。
- `tests/test_favicon.py`：`assert_favicon` 同時檢查 apple-touch-icon link 與檔案路徑；新增 `test_apple_touch_icon_is_180_png`（解析 PNG IHDR 驗證 180x180）。

### 第一次修完仍沒有圖示

- **現象**：使用者回報「還是沒有」。
- **根本原因**：網站只在 `daily_report` workflow 執行時部署到 gh-pages。當天主排程（台北 13:00）早於 commit（16:02），新圖示未上線。
- **處理**：手動 `gh workflow run daily_report.yml --ref main -f date=2026-11-26 -f notify=false`（run 45963030747 成功）。之後確認線上 `https://haolun588.github.io/MLB-daily/assets/apple-touch-icon.png` 回 200 `image/png`，首頁含 link。使用者刪除舊捷徑重新加入主畫面後，logo 出現。

### 文件同步

- `docs/progress.md` 新增階段二十五。
- `docs/architecture.md` 的 `site/` 檔案清單補上 `favicon.svg`、`apple-touch-icon.png`。
- `docs/dev_rules.md` 部署段落補上兩條規範：頁面 head 需同時含兩個 icon link；靜態資源修改後需手動 `workflow_dispatch`（`notify=false`）補部署。
